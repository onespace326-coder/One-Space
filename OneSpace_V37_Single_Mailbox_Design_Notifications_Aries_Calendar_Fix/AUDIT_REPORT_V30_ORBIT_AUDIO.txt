ONESPACE V30 — ORBIT INTRO + ARIES CHROME AUDIO AUDIT
Date: 06 Nov 2026
Base: OneSpace V29 Aurora Premium package

CHANGES
1. Replaced the crescent identity mark in the login and workspace with a bespoke orbital OneSpace monogram.
2. Added a cinematic opening splash with luminous orbit rings, perspective grid, animated emblem and wordmark. It dismisses after load and has a safety timeout; reduced-motion users get a minimal transition.
3. Added V30 design stylesheet, PWA theme colour and service-worker cache update.
4. Replaced the previous speech controller with a single V30 controller that is loaded after legacy scripts, so all existing callers use the final implementation.
5. Voice choice now falls back from selected voice -> exact language -> same language -> English -> system default -> first installed voice. Utterance language follows the selected installed voice when present, preventing a Hindi locale from being forced onto an English-only installed voice.
6. Long responses are split into short queued utterances.
7. Removed unconditional speechSynthesis.cancel() on every new response. Cancellation occurs only when an existing queue is active, reducing queue-reset races.
8. Added actionable error messages, replay control, start timeout, status diagnostics and speech lifecycle events.

NOT CERTIFIED IN THIS ENVIRONMENT
- Audible output in the user's Chrome profile or operating system.
- Live Google OAuth/Gmail/Calendar integrations and Supabase authentication.
- Chrome site Sound permission, tab mute, OS output device and OS voice installation are controlled by the user's browser/device and cannot be overridden by website code.

DEPLOY
Extract all files to the existing GitHub Pages repository root, replace matching files, commit, wait for Pages, then hard refresh Chrome. In Settings > Voice select Auto and press Play voice sample. Test with a short Aries text reply. If silent, check site Sound = Allow, tab not muted, OS output device/volume, then use the visible Tap to hear Aries button or inspect the diagnostic message.

No SQL migration or Supabase data change is required.
